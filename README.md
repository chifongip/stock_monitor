# stock_monitor

A stock monitoring application for tracking real-time stock prices.

# Installation

```
npm install
npm run build
```

## GNOME Shell extension

The GNOME Shell 42 top-bar extension lives in
[`gnome-shell-extension/`](gnome-shell-extension/README.md). Package it with
`make extension-package`, install it with `make extension-install`, reload
GNOME Shell, and then run `make extension-enable`.
